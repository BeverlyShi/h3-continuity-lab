# 视频镜头写作

当前 narrative 决定本场次发生什么；只把已有内容表达成镜头，不继续编写剧情。

术语：一个 narrative 是一个**场次**；一个 prompt 是一**段**，提交一次生成得到一个视频文件；段内两次硬切之间的连续画面是一个**镜头**。

## 核心原则

prompt 的读者是一个没有剧本、没有地图、没有上一镜记忆的视频模型，它只认镜头。每一句话都必须能被摄像师和演员直接执行。

- 规则一：空间关系只用画面坐标，不用故事地理。合法：画面左侧、画面右侧、前景、背景、面向镜头、背对镜头、从画面右侧走入。非法：宫道侧面、回廊那头、门内两步处、廊下、从某处走来，以及一切不以画面为参照的位置。故事地点只能作为背景描述出现，例如“背景是回廊与灯笼”。
- 规则二：画面内容一变，镜头必须先变。凡是新的构图、新的主体、新的景别，都以一句镜头指令开头。没有镜头指令的画面内容一律不许出现：单独一句“衣摆被微风吹动”是非法的，必须先写“镜头切换为特写，机位极低”。

## 先拆镜头，再写镜头

不要把 narrative 按时间顺序翻译成文字再插几句镜头指令。先当分镜师，再当写手：

1. **先拆节拍。** 把这一段要拍的内容拆成节拍：谁说了哪句、谁有什么反应、什么动作或物件是关键。每个关键节拍一个镜头，然后再逐镜写。
2. **一个镜头一个看点。** 画面里可以有多个人（双人对峙、群像都正常），但这一刻观众该看什么要明确。多人同框时写清相对关系、距离和视线；写到的所有人和动作都必须装得进这个画框。几个人各做各的、彼此无关时，拆成几个镜头。
3. **对话用正反打。** 说话人一个镜头；听者的反应切到听者的反打镜头，不塞进说话人的镜头里。需要同时交代双方时用过肩镜头。
4. **写清画框。** 每个镜头都要说明拍到哪些人、各拍到哪个部位（面部、胸口到头顶、腰部以上、只有双手、只有物件），其他人物入不入镜、以什么方式入镜（不入镜、背影、前景虚化的肩头、只伸进一只手）。“特写，她递木牌”是模糊的；“画面只有沈令仪的双手和木牌，人物面部不入镜”才是清楚的。
5. **动作配景别。** 每个动作只写进能看清它的镜头。全景只管站位、关系和大动作（走入、转身、跪下）；眼神、表情、手上的小动作在全景里看不见，要么单独给近景或特写，要么不写。同一个人的连续动作（先打量、再开口）可以留在同一个镜头。镜头数量有限，剧情上关键的小动作给镜头，不关键的删掉，不要写成看不见的描写。
6. **景别对照：**

| 这一拍的内容 | 镜头 |
|---|---|
| 人物站位、关系变化、有人入场或离场 | 全景或双人中景 |
| 有人说话 | 说话人近景或中近景，可用过肩 |
| 听者的反应 | 反打，听者近景 |
| 手部动作、关键物件（腰牌、名册） | 特写，写明画面里只有什么 |

## 一个镜头的固定写法

四层，顺序不能乱：

```
[镜头] 景别 + 机位高度/角度 + 固定或运动 + 切入方式（首镜不写切入）
[画面] 画框里有谁、拍到哪个部位 → 主体在画面哪个位置 → 朝向 → 持物 → 正在做的动作；两人以上必须写出相对关系、距离和视线
[台词] 谁说、说话时面向哪里；在实际说话位置写 {{line_x}} 占位符
[声音] 本镜头内的环境音或动作音，一句；没有明显声音写“安静”
```

- 景别词固定用：远景、全景、中景、中近景、近景、特写。机位词：平视、俯视、仰视、低机位、极低机位。运动词：固定、推近、拉远、横摇、跟随。切入写“镜头硬切为……”或“镜头切换为……”。
- prompt 由若干时间块组成，每块以“0–3秒：”开头，从 0 秒开始首尾相接，最后一块结束于本段 seconds。一个时间块允许包含多个镜头，但每次切镜必须显式写“镜头硬切为 / 镜头切换为 + 景别”。建议 5 秒内不超过 2 个镜头，每个镜头至少 2 秒。
- 双人镜头必须写清谁在画面左、谁在画面右、朝向如何；切镜后以新画面重新定义左右关系。
- 多人镜头必须写出人物之间的关系，三样缺一不可：相对关系（面对面相对而立 / 并肩同向 / 背对背 / 一前一后 / 围站成半圈）、距离（紧挨着 / 相距一臂 / 相距两三步 / 隔着某物）、视线（对视 / 一方看着另一方而另一方垂眼 / 都望向画外同一处）。高度有差时写一站一坐、一站一跪。只写“左侧一人、右侧一人”是不够的，模型会把两人画成互不相干。
- 台词：占位符前写清说话人及其朝向，例如“她面向画面左侧开口，{{line_1}}”。占位符后不要再加句号，程序会替换成姓名与带引号的原台词。全场次每句台词按原顺序恰好使用一次，不删改、不遗漏、不重复、不换说话人。
- 画面里有人张嘴，就必须对应一个 {{line_x}}。没有台词的“开口、说道、答道、回答、应声”会被程序拒绝：模型会给它配上随机人声。
- 声音只写画内或明确的画外声音，“画外传来脚步声”合法；不虚构衣料声、道具音或环境声。无音乐、无旁白由程序追加。
- seconds 要装得下本段台词和动作：台词按每秒 3.5 个汉字估算，再加不能与说话同时完成的动作与停顿。一个场次 2–3 段，每段 5–15 秒，整场 15–45 秒。装不下时先删不关键的镜头和无来源的修饰，仍放不下就用 skipVideo.reason 说明冲突，保留全部原台词与关键事件。

没有分镜意识：

```
0–4秒：全景，平视，镜头固定。青帷小轿停在画面右侧，沈令仪怀抱青布包袱立于轿旁、身体朝左；手持拂尘的老太监立于画面左侧、面向右。两人面对面相对而立，相距两三步，老太监上下打量她，沈令仪垂着眼帘。暮色中朱红宫门与围墙在背景，轿子落地的余响渐静。

4–9秒：镜头硬切为老太监中近景，平视，固定。老太监站在画面中央偏左，拂尘搭在臂弯，目光落在她身上开口，{{line_1}}这句话尚未说完时，沈令仪从右侧入画半步，双手从怀里取出一块木牌递向画面左侧，指尖在牌面上一停。安静。
```

问题：全景里写了“打量”“垂着眼帘”，这个景别看不清；“老太监中近景”里塞进了沈令仪入画、掏牌、指尖停顿，画框装不下，主体也不清；递腰牌这个关键动作没有自己的镜头，也没写画框里有什么。

有分镜意识：

```
0–2秒：全景，平视，固定。暮色中朱红宫门与围墙在背景。青帷小轿停在画面右侧，沈令仪怀抱青布包袱立于轿旁，身体朝左；手持拂尘的老太监立于画面左侧面向她。两人面对面，相距两三步。轿子落地的余响渐静。

2–6秒：镜头硬切为老太监近景，平视，固定。画面只有老太监一人，画框从胸口到头顶，他面向画面右侧，目光从上往下打量，再抬回平视，开口，{{line_1}}

6–8秒：镜头硬切为沈令仪中近景，平视，固定。画面只有沈令仪一人，画框从腰部到头顶，她面向画面左侧垂着眼帘，从怀中取出一块木牌，双手向画面左侧递出。安静。

8–10秒：镜头切换为特写，平视，固定。画面只有沈令仪的双手和木牌，人物面部不入镜；双手托着木牌伸向画面左侧，指尖在牌面上停住。安静。
```

## narrative 里的概述怎么拍

narrative 是写给玩家读的，可能有概述：转述的说话、压缩的时间、抽象的评价。视频模型拍不出概述，prompt 里只能二选一：变成具体可见的画面，或者跳过。

| narrative 里的概述 | prompt 里的处理 |
|---|---|
| 转述的说话（答得又快又响、低声交谈） | 跳过，不写这个人开口；原文有可见部分时只写不出声的动作 |
| 时间压缩（轮过四五人、半个时辰后） | 不拍过程，只拍压缩之后的状态 |
| 抽象评价或气氛（神情精明世故、气氛凝重） | 换成具体的表情或动作；换不成就删 |
| 群体的模糊人声（众人议论） | 只在声音层写“远处传来模糊人声”，不安排画面里任何人张嘴 |

## 画面里的人只能通过两种方式出现

视频模型只看画面，不知道谁“在场”；剧本里在场而镜头里没拍到的人，对它不存在。一个人物要在画面里出现，只有两种方式：

- 建立镜头：换场景时的第 1 段，第一个镜头必须把这一段会出现的所有人物都放进画面，用全景或中景写清每个人在画面哪一侧、相对关系、距离和视线。之后的近景、特写是从建立镜头里“取”人，不是“加”人。接着上一段或上一场次拍的段，画面参考帧里的画面就是建立镜头，画面里没有的人只能靠入画动作进来。
- 入画动作：建立镜头之后才到场的人物，必须有一个镜头写出他的进入：从画面哪一侧走入、走到谁旁边停下、面向谁。离开画面同理，要写出走出画面的方向。

禁止上一镜画面里没有的人，下一镜直接出现在双人或多人镜头里；也禁止上一镜有的人，下一镜无交代地消失。段与段之间同样适用：后一段开场的人物就是上一段末镜里的人物，之后的增减要写出入画或出画。

反例：

```
0–2秒：全景，平视，固定。沈令仪怀抱青布包袱站在画面右侧的石板甬道上，身后是朱红宫门。远处传来断续人声。

2–6秒：镜头硬切为双人中近景，平视，固定。掌事姑姑立于画面左侧，面向右侧的沈令仪开口，{{line_1}}安静。
```

问题：掌事姑姑在 2–6 秒凭空出现，前一镜没有任何镜头让她进入画面。

改法一，用建立镜头在首镜就放进两人：

```
0–2秒：全景，平视，固定。沈令仪怀抱青布包袱站在画面右侧的石板甬道上；提着灯笼的掌事姑姑立于画面左侧。两人面对面相对而立，相距两三步。远处传来断续人声。

2–6秒：镜头硬切为双人中近景，平视，固定。画框从两人腰部到头顶，掌事姑姑在画面左侧面向右侧的沈令仪开口，{{line_1}}安静。
```

改法二，用入画动作写出她的进入：

```
0–3秒：全景，平视，固定。沈令仪怀抱青布包袱站在画面右侧的石板甬道上；提着灯笼的掌事姑姑从画面左侧走入，走到沈令仪面前停下。两人面对面相对而立，相距两三步。脚步声由远及近后停住。

3–6秒：镜头硬切为双人中近景，平视，固定。画框从两人腰部到头顶，掌事姑姑在画面左侧面向右侧的沈令仪开口，{{line_1}}安静。
```

## 每一段必须自足

- 每一段是独立的一次生成调用，模型对上一段一无所知，只能看到程序传入的参考图：本段出场人物的形象参考图，以及第 2 段起上一段的最后一帧（作为画面参考图，本段从这个画面接着拍）。
- 人物外观由程序处理：选了演员且有参考图的人物，程序在 prompt 开头写“某某——人物形象参考图N”并把图传给模型；还没有参考图的，程序拼入选角时写的 appearance。正文只用姓名，不写外貌、不编图号。没有演员的背景人物，每段第一次出现时带一句稳定外观（年龄、服装、标志物），各段一致。
- style 只写必要的质感与光线，保留原文的时间和环境。
- 段与段之间是连续画面：后一段从前一段的最后一帧接着拍，交界处切不了镜头，换镜头只能放在段内部。
- 第 2 段起，开头写“承接上一段画面”，不再重述站位和构图，直接写这一段发生的动作和变化；画面交给参考帧负责，文字只负责变化。这样即使上一段生成得略有偏差，文字也不会与参考帧打架。
- 场次第 1 段接着上一场次拍（opening: continue）时，首镜按 inspect_last_frame 返回的画面写：同样的人物、位置、朝向和景别，不能开场切到与该帧无关的画面。
- 参考帧只约束开场视觉状态，不要为了承接它重演上一场次的问答。人物移动、转向和持物变化必须有原文依据，抱着包袱不能突然变成双手交握。

## 原文覆盖与边界

- narrative 是唯一事件依据。先核对本场次每个可见事件、人物出场、实际发声及最终状态，再安排镜头。
- choices 是尚未发生的选择，不能演出；但不得因此删掉 narrative 中已经发生的结尾。最后一句台词不等于剧情结束，台词之后的转场、开门、新人物出现同样要拍完。
- 上一场次的问话不是当前镜头里的新事件。原文从作答开始，就从作答拍起。
- 不添加原文没有的道具、表演和反应，不用攥帕、欠身、抿唇、看向另一个人等惯用表演替换原文。心理描写不扩写成动作。
- 哼声、笑声即使不在 dialogues 里，也按原文时机写入当前镜头。

## 禁止清单

- 故事地理方位词：侧面拍摄、从某处走来、门内、廊下、回廊那头等。
- 用“画外”做视觉描述；“画外”只能用于声音。
- 没有镜头指令的画面内容。
- 没有台词占位符的开口、说话、回答。
- 画框装不下的内容：近景里写别人的动作、全景里写眼神和指尖。
- 一个镜头里写两个主体各自的动作，却不说明相对关系、距离和视线。
- 上一镜没有的人物直接出现在下一镜，或有的人物无交代地消失。
- 文学修辞、心理描写和概述：沉吟片刻、脆生生、心中一紧、答得又快又响等，一律改写成可见动作和可听声音，改不了就删。
- 抄写台词正文、输出人物 ID、写外貌或编图号。

## 结构示例

人物设定：沈令仪与掌事姑姑都已选角，外观由程序处理，正文只用姓名；掌事姑姑手里提着灯笼。line_1 是姑姑问“哪家的姑娘？”，line_2 是沈令仪答“江南沈家嫡女，名唤令仪。”。

第 1 段（8 秒）：

0–3秒：全景，平视，镜头固定。青石板路上，沈令仪怀抱青色包袱立于画面左侧，身体朝右；提着灯笼的掌事姑姑从画面右侧走入，走到沈令仪跟前停下，两人面对面相对而立，相距一步。脚步声由远及近后停住。

3–5秒：镜头硬切为掌事姑姑近景，平视，固定。画面只有掌事姑姑一人，画框从胸口到头顶，她面向画面左侧，目光从上往下打量，开口，{{line_1}}

5–8秒：镜头硬切为过肩近景，平视，固定。前景是掌事姑姑虚化的肩头，位于画面右侧；焦点在画面左侧沈令仪的脸上，她垂着眼面向右侧开口，{{line_2}}安静。

第 2 段（5 秒）：

0–2秒：承接上一段画面，镜头固定。沈令仪说完抬起眼，与画面右侧的掌事姑姑对视。安静。

2–5秒：镜头硬切为掌事姑姑近景，平视，固定。画面只有掌事姑姑一人，画框从胸口到头顶，她看着画面左侧，嘴角微微一动，手中灯笼的暖光映在脸上。安静。

第 2 段没有重述站位和外观，只写了从参考帧出发的变化；说话与反应分在正反打的不同镜头里。示例中的动作仅用于说明写法，原文没有就不要照搬。

## 提交前自查

先查分镜：每个关键节拍是否有自己的镜头；对话是否用了正反打，反应是否切到了听者；每个镜头是否写清了画框里有谁、拍到哪个部位；全景里有没有写看不清的眼神和小动作；近景或特写里有没有塞进画框外的人的动作。

再查写法：每个镜头是否以景别开头；方位是否全部是画面坐标；每次画面变化是否先写了镜头指令；每个开口是否都有台词占位符，narrative 里的概述是否已变成可见画面或删掉；没有演员的人物在本段是否写了外观，有演员的人物是否只写了姓名；换场景的首镜是否把本段所有人物都放进了画面，后到的人物是否写了入画动作；第 2 段起是否以“承接上一段画面”开头、没有重述构图，段与段交界处没有切镜；多人镜头是否写了相对关系、距离和视线；台词占位符是否恰好对应原文且后面没有多余句号；原文事件与声音是否全部覆盖，有无新增道具、表演和上一场次的问话；实际内容是否装得进 seconds；末镜是否写清了最终构图并到达 narrative 最后的可见状态。校验错误时定向修正，不重写已发布剧情。
