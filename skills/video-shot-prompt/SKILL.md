# 视频镜头写作

当前 narrative 决定本幕发生什么；只把已有内容表达成镜头，不继续编写剧情。

## 原文覆盖与边界

- 先核对本幕每个可见事件、人物出场、实际发声及最终状态，再安排镜头。最后一句台词不等于剧情结束；台词之后的转场、开门、新人物出现同样必须呈现。
- choices 是尚未发生的选择，不能演出。但不得因此删掉 narrative 中已经发生的结尾。
- 上一幕的问话不是当前镜头里的新事件。原文从作答开始，就从作答拍起，不添加“某人问话后”等未交代的前置行为。
- 已有的视线、表情、动作、道具和发声忠实保留；没有依据的不添加。不能用攥帕、欠身、抿唇、看向另一个人等惯用表演替换原文。心理描述不自动扩写成新动作。
- 身世回顾和心理独白不必逐句转成画面；关键可见事件不能以“背景”为由略去。哼声、笑声即使不在 dialogues 里，也要按原文时机写入当前镜头。

## 场景和参考素材

- style 只写必要的质感与光线，保留原文的时间和环境。整幕允许 narrative 已有的转场，每个镜头明确当前小空间，不能把整幕强行固定在一处。
- 有参考图的人物保持图中外观，不重复描写外貌，不编造图号。没有参考图的新人物只给最低限度的稳定外观设定，不改变原文已有服装或添加道具。
- 首段有起始尾帧时只提供尾帧，人物图不再附上；没有尾帧时按 characters 顺序附有图人物的参考图。以本回合实际素材为准，不沿用历史回合的假设。
- 起始尾帧只约束开场视觉状态；不要为了承接尾帧重演上一幕的问答。人物移动、转向和持物变化必须有原文依据，抱着包袱不能突然变成双手交握。

## 每个时间块就是一个镜头

- prompt 由若干时间块组成，每块以“0–3秒：”开头，从 0 秒开始首尾相接，最后一块结束于本段 seconds。一块围绕一个主要事件；换镜头就新开一块。
- 每块先写唯一的景别、机位高度、拍摄方向及固定或具体运动，再写实际入画的人数、位置、朝向、持物和动作。双人镜头不能同时描写三人在画内；画外人物注明画外。切镜后以新画面重新定义左右关系。
- 按实际先后写动作，在说话的准确位置插入 {{line_1}} 形式的占位符。程序会替换成人物姓名与完整原台词。全幕每句台词按原顺序恰好使用一次，不删改、不遗漏、不重复、不换说话人；正文不抄写台词，不输出人物 ID。
- 说话中的反应明确写“这句话尚未说完时……”并放在同一块，不把同时发生的打断拆成台词结束后的反应镜头。
- 声音写在同一块末尾，只写本镜声音及发生时机。原文的哼声、低笑等保留，不虚构衣料声、道具音或环境声；没有明显声音写“安静”。无音乐、无旁白由程序统一追加。
- seconds 要装得下这一段的台词和动作：台词按每秒 3.5 个汉字估算，再加不能与说话同时完成的动作与停顿；不能靠加快语速或遗漏事件塞进时间上限。
- 一幕 2–3 段，每段 5–10 秒，整幕 15–30 秒。装不下时先精简无来源修饰并重新分配镜头与台词；仍放不下就在 finish_turn 前说明冲突，保留全部原台词与关键事件。

## 结构示例

仅当本幕原文是“女主望着姑姑，欠身说出 line_1，随后直起身”时，可写：

0–4秒：固定双人中近景，机位与视线齐平，从两人侧面拍摄。女主位于画面左侧，姑姑位于右侧，两人相对。女主望着姑姑，欠身，{{line_1}}。说完直起身。安静。

示例中的欠身、直起身仅用于说明台词插入位置，原文没有就不要照搬。

## 提交前自查

逐条检查原文事件与声音是否覆盖，有无新增道具、表演和上一幕的问话；台词占位符是否恰好对应原文；人数、画内外、朝向、持物是否连续；动作和对白的先后/重叠是否保留；实际内容是否装得进 seconds；末镜是否到达 narrative 最后的可见状态。校验错误时定向修正，不重写已发布剧情。
