# 视频镜头写作

当前 narrative 决定本幕发生什么；只把已有内容表达成镜头，不继续编写剧情。

## 核心原则

prompt 的读者是一个没有剧本、没有地图、没有上一镜记忆的视频模型，它只认镜头。每一句话都必须能被摄像师和演员直接执行。

- 规则一：空间关系只用画面坐标，不用故事地理。合法：画面左侧、画面右侧、前景、背景、面向镜头、背对镜头、从画面右侧走入。非法：宫道侧面、回廊那头、门内两步处、廊下、从某处走来，以及一切不以画面为参照的位置。故事地点只能作为背景描述出现，例如“背景是回廊与灯笼”。
- 规则二：画面内容一变，镜头必须先变。凡是新的构图、新的主体、新的景别，都以一句镜头指令开头。没有镜头指令的画面内容一律不许出现：单独一句“衣摆被微风吹动”是非法的，必须先写“镜头切换为特写，机位极低”。

## 一个镜头的固定写法

四层，顺序不能乱：

```
[镜头] 景别 + 机位高度/角度 + 固定或运动 + 切入方式（首镜不写切入）
[画面] 主体是谁 → 在画面哪个位置 → 朝向 → 持物 → 正在做的动作
[台词] 谁说、说话时面向哪里；在实际说话位置写 {{line_x}} 占位符
[声音] 本镜头内的环境音或动作音，一句；没有明显声音写“安静”
```

- 景别词固定用：远景、全景、中景、中近景、近景、特写。机位词：平视、俯视、仰视、低机位、极低机位。运动词：固定、推近、拉远、横摇、跟随。切入写“镜头硬切为……”或“镜头切换为……”。
- prompt 由若干时间块组成，每块以“0–3秒：”开头，从 0 秒开始首尾相接，最后一块结束于本段 seconds。一个时间块允许包含多个镜头，但每次切镜必须显式写“镜头硬切为 / 镜头切换为 + 景别”。建议 5 秒内不超过 2 个镜头，每个镜头至少 2 秒。
- 双人镜头必须写清谁在画面左、谁在画面右、朝向如何；切镜后以新画面重新定义左右关系。
- 台词：占位符前写清说话人及其朝向，例如“她面向画面左侧开口，{{line_1}}”。占位符后不要再加句号，程序会替换成姓名与带引号的原台词。全幕每句台词按原顺序恰好使用一次，不删改、不遗漏、不重复、不换说话人。
- 说话中的反应写“这句话尚未说完时……”，与台词放在同一个镜头，不拆成台词结束后的反应镜头。
- 声音只写画内或明确的画外声音，“画外传来脚步声”合法；不虚构衣料声、道具音或环境声。无音乐、无旁白由程序追加。
- seconds 要装得下本段台词和动作：台词按每秒 3.5 个汉字估算，再加不能与说话同时完成的动作与停顿。一幕 2–3 段，每段 5–10 秒，整幕 15–30 秒。装不下时先精简无来源的修饰并重新分配镜头，仍放不下就在 finish_turn 前说明冲突，保留全部原台词与关键事件。

## 每一段必须自足

- 每一段是独立的一次生成调用，模型对上一段一无所知，只有一张起始尾帧图。
- 没有参考图或参考图待生成的人物，在每一段第一次出现时都要带一句稳定外观（年龄、服装、标志物），不能只在第一段写；各段之间的外观描述必须一致。
- 外观优先使用选角时写下的 appearance 原文，保证与将来的参考图一致。
- 有参考图的人物只用姓名，程序会在段首注明“外观与图 N 一致”，不要自己编图号或重复描写外貌。
- style 只写必要的质感与光线，保留原文的时间和环境。
- 第二段起，第一个镜头应当延续上一段末镜的构图，即同样的人物位置、持物和朝向，不能开场切到与尾帧无关的画面；因此上一段的末镜要把最终构图写清楚。
- 起始尾帧只约束开场视觉状态，不要为了承接尾帧重演上一幕的问答。人物移动、转向和持物变化必须有原文依据，抱着包袱不能突然变成双手交握。

## 原文覆盖与边界

- narrative 是唯一事件依据。先核对本幕每个可见事件、人物出场、实际发声及最终状态，再安排镜头。
- choices 是尚未发生的选择，不能演出；但不得因此删掉 narrative 中已经发生的结尾。最后一句台词不等于剧情结束，台词之后的转场、开门、新人物出现同样要拍完。
- 上一幕的问话不是当前镜头里的新事件。原文从作答开始，就从作答拍起。
- 不添加原文没有的道具、表演和反应，不用攥帕、欠身、抿唇、看向另一个人等惯用表演替换原文。心理描写不扩写成动作。
- 哼声、笑声即使不在 dialogues 里，也按原文时机写入当前镜头。

## 禁止清单

- 故事地理方位词：侧面拍摄、从某处走来、门内、廊下、回廊那头等。
- 用“画外”做视觉描述；“画外”只能用于声音。
- 没有镜头指令的画面内容。
- 一个镜头里写两个主体各自的动作却不说明构图。
- 文学修辞和心理描写：沉吟片刻、脆生生、心中一紧等，一律改写成可见动作和可听声音。
- 抄写台词正文、输出人物 ID、在画面描述里编图号。

## 结构示例

人物设定：沈令仪有参考图；掌事姑姑没有参考图，四十余岁、着深青宫装、提着灯笼。line_1 是姑姑问“哪家的姑娘？”，line_2 是沈令仪答“江南沈家嫡女，名唤令仪。”。

第 1 段（7 秒）：

0–4秒：全景，平视，镜头固定。青石板路上，沈令仪怀抱青色包袱立于画面左侧，身体朝右；一位四十余岁、着深青宫装、提着灯笼的掌事姑姑从画面右侧的回廊走入，走到沈令仪跟前停下，两人相对而立，姑姑上下打量她。脚步声由远及近后停住。镜头硬切为掌事姑姑近景，平视，固定。她面向画面左侧开口，{{line_1}}

4–7秒：镜头硬切为双人中近景，机位略高俯视，固定。沈令仪在画面左侧微微屈膝，面向右侧的姑姑开口，{{line_2}}镜头切换为特写，极低机位贴近地面，固定。画面中两人的衣摆下沿被晨风吹起轻轻晃动，灯笼的暖光映在衣料上。衣料窸窣。

第 2 段（5 秒）：

0–5秒：特写，极低机位，固定，延续上一段末镜的衣摆画面。镜头缓缓上摇至双人中近景：沈令仪在画面左侧直起身，面向右侧；四十余岁、着深青宫装、提着灯笼的掌事姑姑在画面右侧，目光停在她脸上。安静。

第 2 段重复了掌事姑姑的外观，首镜延续了第 1 段末镜的构图。示例中的动作仅用于说明写法，原文没有就不要照搬。

## 提交前自查

逐镜检查：每个镜头是否以景别开头；方位是否全部是画面坐标；每次画面变化是否先写了镜头指令；无参考图人物在本段是否写了外观；台词占位符是否恰好对应原文且后面没有多余句号；原文事件与声音是否全部覆盖，有无新增道具、表演和上一幕的问话；实际内容是否装得进 seconds；末镜是否写清了最终构图并到达 narrative 最后的可见状态。校验错误时定向修正，不重写已发布剧情。
