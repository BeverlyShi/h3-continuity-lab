# H3 Continuity Lab

一个通过 fal H3 Max API 验证连续视频生成与实时互动故事体验的 React 前端原型。

## 本地运行

需要 Node.js 20 或更高版本。

```bash
npm install
npm run dev
```

浏览器打开 Vite 输出的本地地址（通常为 `http://localhost:5173`）。

## 验证

```bash
npm run lint
npm run build
```

## 当前交互

页面顶部提供两个独立工作区：

- **视频生成**：保留连续视频生产工作流。
- **游戏互动**：运行《无籍之城》快速版互动故事实验。

### 视频生成

- 在左侧创建、切换项目；每个项目拥有独立的 Prompt 与视频时间轴。
- 输入首个 Prompt 后，时间轴立即加入“生成中”片段，fal 完成后自动播放。
- 后续 Prompt 会依次加入时间轴，完成后成为可播放片段。
- 当前片段结束时，如果下一段已就绪则自动续播；否则停留等待，并在下一段就绪时自动继续。
- 用户主动暂停不会被生成完成事件打断。
- 点击已完成的时间轴片段可以回看，右侧当前 Prompt 会同步切换。
- 单个片段可下载；项目可通过浏览器内 FFmpeg 按时间轴顺序合并为一个 MP4。
- 项目元数据、片段地址和 fal API Key 会保存在当前浏览器的 `localStorage` 中。

### 游戏互动（内置 Pi 导演）

- 游戏初始页展示《无籍之城》的世界背景、玩家身份和四条核心生存规则。
- 点击“开始游戏”后，系统直接使用故事包内的开场 Prompt 调用 fal H3 Max，不要求玩家先输入 Prompt。
- 开始游戏需要 `FAL_KEY` 和 `DEEPSEEK_API_KEY`；前者生成视频，后者驱动世界导演。
- 生成期间显示明确的开场生成状态；成功后在 16:9 播放器中播放第一段 5 秒视频。
- 开场播放结束后提供两个导演建议选项和自由输入；建议选项一点即提交。
- 《无籍之城》第一夜包含四名固定来客、三张宿籍和五个玩家回合。
- 确定性规则引擎限制数值幅度、宿籍数量、日落后流转条件和最终结局。
- 页面内置 Pi Agent Core，并通过本地 `/api/director/turn` 调用 `deepseek-v4-flash` 完成结构化裁决。
- 玩家提交行动后，页面会自动执行“导演裁决 → 确定性规则校验 → H3 生成 → 发布并播放”，不再等待外部 Codex 或 Site Tools。
- 右侧“Pi 世界导演”面板会流式显示裁决进度，也可作为自由行动输入框；失败时可从当前步骤重试。
- 播放器下方保留所有已生成幕次，可随时回看历史视频与叙事；回看不会推进剧情或调用 API。
- DeepSeek 单次导演请求最多输出 2,500 tokens、关闭自动重试并设置 45 秒超时；H3 固定生成 5 秒，每局最多包含开场和五个回合视频。
- 每次通过校验的裁决都会编译为连续镜头 Prompt，并继续调用 fal H3 Max 生成 5 秒视频。
- 生成失败后可在保留当前游戏会话的情况下重新生成；游戏状态和事件记录保存在当前浏览器的 `localStorage` 中。

## API 接入边界

当前版本是本地验证 MVP。`FAL_KEY` 和 `DEEPSEEK_API_KEY` 会以明文形式保存在当前设备的浏览器存储中；DeepSeek Key 只传给本机 Vite 导演接口。正式产品应把两个 Key 都保存在服务端环境变量中，并通过有鉴权的 API Route 调用外部服务。

项目视频仍引用 fal 返回的远程地址，远程资源过期后无法恢复。项目合并依赖浏览器内存和 FFmpeg WebAssembly，长视频或大量片段可能受到设备内存、跨域策略及浏览器下载策略限制。
